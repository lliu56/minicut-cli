# MiniCut CLI downloads

Built files for the MiniCut CLI. Each version is a GitHub Release here, with the downloads and the signed `manifest.json` and `timestamp.json`.

Install:

```sh
curl -fsSL https://minicut.ai/install.sh | sh
```

The install line checks the signature on the manifest and the SHA256 of every file before it installs anything.

The source code is private.
